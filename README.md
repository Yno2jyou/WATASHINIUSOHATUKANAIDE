# 私に嘘はつかないで

2人用の「嘘／本当」見抜きゲームです。

## ファイル構成

すべて同じフォルダに置いてください。

| ファイル | 内容 |
|---------|------|
| `lie-game.html` | ゲーム本体 |
| `intro.mp4` | イントロ動画 |
| `kinuso.mp4` | 正解時の結果動画 |
| `kinkan.mp4` | 不正解時の結果動画 |
| `bgm.m4a` | バックミュージック |
| `result-correct.jpg` | 正解画面の画像 |
| `result-wrong.jpg` | 不正解画面の画像 |

## 遊び方（ローカル）

`lie-game.html` をブラウザで開くだけです。  
※ 動画・音声は同じフォルダから読み込みます。

## GitHub Pages で公開する場合

1. 上記ファイルをすべてリポジトリに push
2. Settings → Pages → Deploy from branch で公開
3. `https://<user>.github.io/<repo>/lie-game.html` でアクセス

ファイルは分割済みなので、GitHub のサイズ制限には引っかかりません。
